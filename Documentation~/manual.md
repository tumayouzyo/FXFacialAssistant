# 操作マニュアル

## 表情とプレビュー

Hierarchyのアバターを指定し、BlendShapeを持つBodyを自動選択。別メッシュは「編集メッシュ」または「選択中メッシュを指定」から指定する。編集は専用プレビュー内だけに反映する。

右ドラッグで回転、中ドラッグで高さ調整、ホイールで距離調整。上へ中ドラッグするとカメラが下がる。焦点距離の初期値は85mm（35mm判換算）。

「保存」で画角を保存し、「適用」で復元。「正面」は回転を0に戻す。保存済み画角は次回起動時にも復元する。

## デフォルト表情と読み込み

「デフォルト表情を指定」でAnimationClipを選択し、10f記録の始点にする。未指定時はメッシュ指定時の値を使用。「読み込み」でスライダーに適用し、「保存」で現在の全項目を指定クリップへ保存する。別名コピーしたクリップを推奨。

「アニメーション読み込み」でクリップを指定すると、その下に0～100%の位置スライダーを表示する。「適用」をオンにすると選択位置の値で表情スライダーを完全に置き換える。オフにしても現在値は維持する。選択メッシュのパスに一致しない項目、未収録項目は0。元のキー配置は保持しない。

## 記録と保存

左端チェックは記録対象。チェックを外してもプレビュー値は維持。「編集項目のみチェック」はデフォルトとの差がある表示項目だけを選択する。末尾の「補間」チェックは、デフォルトから現在値まで0～10フレーム（60fps）で直線補間する。

「表情アニメーションを保存」「透過アイコンを保存」は独立。初期保存先はFX Controllerの隣のFacialフォルダ。「フォルダ選択」で変更し、「既定」で戻す。「保存先をハイライト」は存在するフォルダをProjectで示す。未作成なら案内のみ表示する。

初期ファイル名はFA_名前.anim／FA_名前.png。同名保存は確認して上書きし、GUIDを維持する。接頭辞は保存名欄の末尾で切り替える。クリップ指定時はそのフォルダを保存先にし、接頭辞をオフにする。「クリア」は指定をNoneにし、接頭辞をオンにする。編集値と保存先は維持。「既定」はFX基準の保存先へ戻し、接頭辞をオンにする。アイコンは256×256透過PNGで、Expression Menu向けImport Settingsを適用する。

## FX操作

Left Hand／Right HandのステートへClipを指定する。SubStateMachineは折りたたみ表示。共有Controllerへの変更は共有先にも反映される。レイヤーやステートは自動作成しない。

「empty自動設定」は対象レイヤーと配下のMotionがNoneのステートへSDKのproxy_emptyを設定する。既存Motionは維持し、Ctrl+Zで戻せる。

「クリーンアップ」はBroken text PPtrの原因となる、FX内の存在しないローカル参照を解除する。正常な参照・外部参照・文字列は保持。確認後、元ファイルとmetaをLibrary/TY_FXFacialAssistantBackupへ退避する。未保存のFX変更がある場合は先に保存する。

## 設定

表示言語は日本語／英語。言語と接頭辞の変更は即時保存。ブラックリストは1行1ルール、大文字小文字を区別しない。*は任意の文字列、?は1文字。ブラックリストの変更は「適用して閉じる」で保存する。

## 制約と連絡先

プレビューは元アバターのポーズとRendererの状態を使用し、PhysBone、Constraint、NDMFなどの動作は再現しない。BlendTree、同期レイヤー、AnimatorOverrideControllerの編集は未対応。

SDK 3.10.6のImport Workerに関する問題は[トラブルシューティング](troubleshooting.md)を参照。
